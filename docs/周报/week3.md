### 实验报告

#### 实验思路

本阶段围绕两个问题展开：一是比较不同模型能否有效区分高低风险客户；二是在选定XGBoost后，检验补充业务信息和调整模型能否提高后续时期的识别表现。评价不仅关注AUC，也结合违约识别率和正常客户误标，区分“模型分数变化”与“实际业务价值”。

#### 实验过程

**三模型对比**

逻辑回归、随机森林和XGBoost共用93个特征，使用同一划分，训练、验证和测试样本分别为560,000、160,000和80,000条。最终确定优化XGBOOST模型，对比结果如下：

| 模型     | 验证集AUC | 测试集AUC | 测试集KS |
| -------- | --------- | --------- | -------- |
| 逻辑回归 | 0.7064    | 0.6958    | 0.2870   |
| 随机森林 | 0.7071    | 0.7035    | 0.2990   |
| XGBoost  | 0.7158    | 0.7124    | 0.3147   |

XGBoost在验证集和测试集的风险排序表现领先；其最低风险档和最高风险档的观察坏账率分别为3.44%和43.54%，体现出较好的客群区分能力，因此继续以其作为优化对象。

**第一轮优化**

- 重新划分样本
- 时间交叉验证
- 匿名特征聚合

**第二轮优化**

- 新增16项业务特征
- 完成50次搜索，同时比较沿用基线参数、沿用第一轮最优参数及重新搜索三种方案。

#### 实验结果

两轮优化使用相同的训练集558,371条、验证集161,731条、测试集79,898条，最终模型按验证集结果选定，不根据测试结果重新选择。

| 比较方案                | 验证集AUC       | 测试集AUC       | 测试集违约识别率（Recall） |
| ------------------- | ------------ | ------------ | ---------------- |
| 优化阶段基线              | 0.697218     | 0.722006     | 9.66%            |
| 第一轮调优               | 0.701199     | 0.719789     | 6.69%            |
| 第二轮最终选定：新特征＋第一轮最优参数 | 0.701531 | 0.719774 | 7.11%        |
| 第二轮重新搜索，未选用         | 0.698604     | 0.715341     | 4.96%            |

第二轮最终模型与第一轮调优模型的测试AUC基本持平。相比第一轮，其多识别68名违约客户，同时多误标62名正常客户，风险覆盖增大同时审核成本上升。

## 二、思考沉淀

- 特征重在贴合业务，不是越多越好。这次结合存量负债和新增借款完善客户画像；但逻辑合理的特征未必有预测价值，被筛掉大多是信息冗余、区分度不足，不代表业务上不重要。
- 风控要兼顾漏判和误判。模型多抓违约，也会带出更多正常客户复核。模型仅作排查线索，要不要拒贷、配多少审核人力，看业务实际情况。
