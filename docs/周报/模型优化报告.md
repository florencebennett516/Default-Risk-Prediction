# XGBoost优化

> **优化过程归档。** 本文保留第一轮与第二轮试验记录；第二轮的 90 特征方案不等于最终报告选定的第一轮 90 特征方案。最终对外口径以[最终项目报告](../最终报告/最终项目报告.md)为准：按完整月份划分，测试集 79,898 条，同口径基线 AUC 0.7220、选定的调优模型 AUC 0.7198。下文其他轮次仅用于说明迭代过程，不替换最终指标。

 第一轮优化：规范时间划分，补充匿名聚合信息。

- 按完整放款月份固定训练、验证和测试窗口，避免不同试验使用不同样本。
- 对匿名字段n0—n14生成均值、波动、非零数量和缺失数量等聚合特征，补充客户信息的统计描述。
- 完成20次参数搜索，每次采用5折时间验证；最终保留90个特征，按验证集结果选择模型。

第二轮优化：补充业务信息，检验是否有额外价值。

- 根据业务信息新增16项候选特征
- 完成50次搜索，同时比较沿用基线参数、沿用第一轮最优参数及重新搜索三种方案。
- 最终仍保留90个特征，其中新增候选仅有两项入模：

| 新增入模特征                             | 计算方式                                     | 业务含义                                                         |
| ---------------------------------------- | -------------------------------------------- | ---------------------------------------------------------------- |
| 合计偿债收入比（total_dti）              | dti / 100 + installment × 12 / annualIncome | 将已有债务与新增贷款年供放在统一口径下，描述整体偿债压力         |
| 全周期还款收入比（total_payment_income） | installment × term × 12 / annualIncome     | 描述整笔贷款全部分期还款额相对一年收入的规模，不等同年度还款压力 |

## 四、新增特征

| 特征                    | 公式                                                                     | 业务解释                                              |
| ----------------------- | ------------------------------------------------------------------------ | ----------------------------------------------------- |
| new_installment_ratio   | installment * 12 / annualIncome                                          | 新增贷款年供收入比                                    |
| **total_dti**     | **dti / 100 + new_installment_ratio**                              | **新增贷款后合计偿债压力**                      |
| loan_to_income          | loanAmnt / annualIncome                                                  | 本金收入比；不同于原按期限年化的比率                  |
| total_payment_income    | installment * term * 12 / annualIncome                                   | term为年，换算月数后的全周期还款收入比                |
| revol_income            | revolBal / annualIncome                                                  | 循环余额收入比                                        |
| util_high_flag          | revolUtil > 70                                                           | 循环额度高占用                                        |
| util_mid_flag           | 30 < revolUtil <= 70                                                     | 循环额度中等占用                                      |
| open_acc_ratio          | openAcc / totalAcc                                                       | 在用账户占比                                          |
| closed_acc              | totalAcc - openAcc                                                       | 关闭账户数，负数按原流程设为缺失                      |
| delinq_per_acc          | delinquency_2years / (totalAcc + 1)                                      | 近两年逾期密度                                        |
| has_pub_rec             | pubRec > 0                                                               | 公共负面记录标记                                      |
| uncleared_negative      | pubRec - pubRecBankruptcies                                              | 仅为记录数量差，不能识别污点是否已清除                |
| fico_score              | (ficoRangeLow + ficoRangeHigh) / 2                                       | FICO区间中点                                          |
| fico_low_flag           | ficoRange_mean < 660                                                     | 低FICO标记                                            |
| credit_age_month        | 12 * (issue_year - first_credit_year) + issue_month - first_credit_month | 精确信用账龄月数，不等同原年份差                      |
| new_credit_flag         | credit_age_month < 24                                                    | 信用账龄不足24个月                                    |
| short_emp_flag          | employmentLength < 2                                                     | 使用清洗后就业年限，不使用岗位编码                    |
| term_int_burden         | term * interestRate                                                      | 年数乘百分数利率的交互项，不是实际总利息              |
| high_install_flag       | installment / annualIncome > 0.05                                        | 单月月供与年收入之比超阈值                            |
| joint_app_flag          | 待确认applicationType编码                                                | 不生成标记，保留原申请类型                            |
| debt_consolidation_flag | 待确认purpose编码                                                        | 不生成标记，保留原用途                                |
| **n_valid_count** | **count(n0..n14 > 0)**                                             | **替换anonymous_nonzero_count；当前数据无负数** |
| n_missing_count         | count(isna(n0..n14))                                                     | 替换anonymous_missing_count，填补前计数               |
| n_missing_flag          | n_missing_count >= 3                                                     | 匿名字段多项缺失，填补前生成                          |

## 五、结果

两轮优化完善了客户偿债压力的刻画，保留的两项新特征，分别描述“原有债务加新增年供对收入的压力"和“整笔贷款全部分期还款额相对一年收入的规模”。

风险覆盖略有扩大，也增加了误标。 相比第一轮调优模型，第二轮最终模型多识别68名违约客户，同时多误标62名正常客户。

 第一轮重点建立规范的优化与对比流程；第二轮重点补充业务特征、检验其增量价值。
