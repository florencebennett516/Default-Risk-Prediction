### 实验报告

#### 实验思路

  本实验以借款人是否违约为预测目标，结合此前关于缺失值检查、类型转换和内存优化的讨论，采用“特征工程—分层划分—XGBoost建模—多指标评价”的技术路线，利用借款人的偿债压力、信用历史和账户结构识别违约风险。

#### 实验过程

1. 特征构建：基于80万条样本，构造年化贷款收入比、循环余额收入比、开放账户占比、信用历史年限及FICO均值等特征
2. 缺失值处理：匿名特征和职称大量缺失，使用flag标志缺失；其他小部分缺失，如年收入水平，考虑到样本右偏，使用中位数而非均值。
3. 样本划分：对时间排序，按照70%、20%、10%分层划分训练集、验证集和测试集。
4. 聚合特征：进一步构造类别分组统计特征

   1. 一维：类别*连续变量-最大、最小、中位数
   2. 二维：类别*类别-香农熵、最大、最小、众数
5. 特征编码：结合有序编码、独热编码和五折交叉拟合目标编码

7. 参数设置：预处理仅在训练集拟合，数据转为float32。

   1. 采用直方图算法，主要是为提高大样本、多特征条件下的训练效率；
   2. 树深设为5，旨在兼顾非线性关系学习与过拟合控制；
   3. 学习率设为0.05，使模型通过小幅更新逐步学习，并配合最多1000轮提供充分的迭代空间。
   4. 以验证集AUC作为早停依据，连续50轮未提升即停止，避免无效训练。
8. 特征排序：使用最佳轮次模型的 gain排序，展示前 20 个特征

## 二、思考沉淀

### EDA

- 数据缺失概率较大，尝试和时间匹配。例如，早期未建立相应的数据收集方式导致数据缺失。
- 一开始就应该划分数据类型，方便后面重复调用
  - 离散型
    - 类别
      - 低基数
      - 高基数
      - 顺序
    - 时间
  - 连续型
    - 连续
    - 计数
- 始终将目标和变量整合起来，初步筛查特征
- 为了观察分布，可以先在EDA把分箱做好
  - 离散型：
    - 顺序、低基数-柱状图
    - 高基数-kde
  - 连续性
    - 连续-等频分箱
    - 计数-线图

### 特征工程

- 创建特征：着重考察EDA

  - 一维交叉：类别×连续
  - 二维交叉：香农熵、权重
  - 聚合特征：分位数、最大最小值、中位数、平均值
  - 顺着业务逻辑，自己构造特征
- 特征选择：删除完全重复、已经过简单数学处理的变量
- 划分样本：对样本集的划分有id匹配和时间两种方式，金融场景下，选择优先规避时间泄露。
- 特征编码

  - 低基数：独热编码
  - 高基数：目标编码+k折平滑
  - 顺序：map映射
- 更多特殊的特征处理方式，应该放在模型之中再构建。比如均值化，不适合树模型，只放在逻辑回归中即可。先不统一处理。
- 样本检查与声明

### XGBOOST

- 参数：使用直方图算法，树深度 5、学习率 0.05，最多训练 1,000 轮
- 早停：验证集 AUC 连续 50 轮未提升时停止。预测和特征重要性使用最佳轮次对应的模型。
- 特征重要性：按不纯度降序排序得到钱20个最重要的特征
