# 最终项目交付使用说明

## 阅读报告

- `最终项目报告.md` 为文字与表格原稿。
- `最终项目报告.html` 为同内容排版版，可用浏览器打开，也可通过浏览器打印为 PDF；请保留项目目录结构，以便加载图表。
- 原模型结果位于 `results/xgboost_optimization`，本次补充结果位于 `results/final_project`。未覆盖原始数据、已有 notebook 或已训练模型。

## 运行完整流程

1. 打开 `D:/credit/code/main_pipelin.ipynb`
2. 在 VS Code/Jupyter 中选择 `D:/credit/venv/Scripts/python.exe` 对应内核，从第一个单元格依次执行。
3. 默认 `RUN_TRAINING=False`：重新读取原始数据、清洗并核对快照，加载已有最终模型，重放全部 79,898 条测试记录的两套模型概率，重算指标、SHAP、阈值情景和报告。该模式已从头执行通过，结果已保存在 notebook 中。
4. 需要重新训练时，把 `RUN_TRAINING=True`，保持 `N_TRIALS=20` 与既有时间切点不变。该分支包含训练窗口内特征处理、5 折时间验证、Optuna 搜索、验证期选型、合并再训练和测试，可能耗时较长。其输出进入 `results/final_pipeline_runs/<时间戳>`，不覆盖原结果；该分支未重新执行完整 20 次搜索。
5. 若出现数据或预测核验失败，请停止，不要删除断言强行继续；查看对应 audit CSV，并检查输入、模型和预处理模块是否来自同一版本。

Notebook 依赖 `code/model/final_project.py`、`final_report_template.md`、`xgboost_optimization.py` 和 `model_optimization_features.py`，以及项目数据和已保存结果；不是可单独搬走的独立文件。默认重放会更新本次最终报告及其证据，不改原始模型阈值。

## 环境与结果边界

实际运行依赖版本、Python 版本、种子和输入 SHA-256 见 `results/final_project/run_manifest.json`。不建议在现有环境直接升级 sklearn/XGBoost 后加载旧 joblib；复现应优先使用项目现有 venv。仅加载可信本地模型文件。
