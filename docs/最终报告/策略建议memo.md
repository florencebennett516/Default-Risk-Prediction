# 策略建议 memo｜容量约束下的信贷风险复核

日期：2026-11-11｜决策对象：风控与运营｜依据：90 特征 XGBoost，时间外测试 79,898 笔

## 建议决策

**以 cutoff 0.2275 作为风险参考线，优先人工复核最高风险 10%，并以 Top-K 分位队列控制跨期容量。** 先开展辅助复核试点，保留既有审批政策。

## 历史依据

| 策略 / 人群 | 已有结果 | 决策含义 |
| --- | --- | --- |
| cutoff 0.2275 | 验证拒绝率 29.99%；测试 34.63%，约 30%–35% | 固定概率线跨期会超出 30% 预算 |
| 测试通过组 | 坏率 12.40%，总体 19.93%，相差 7.53 个百分点 | 可用作筛选后客户质量的回测参照 |
| 最高风险 10% | 坏率 44.61%，Lift 2.24，捕获 22.38%（约 22.4%）违约 | 将人工核查资源优先用于该队列 |

## 执行规则与容量风险

固定 cutoff 的拒绝比例由验证期约 30% 升至测试期 34.63%，超限 4.63 个百分点。建议按预先确定的日 / 批次申请池排序，令 **K = min（向下取整的 30% × 当批申请数，当批处理容量）**，只将最高风险 K 笔纳入队列；最高风险 10% 优先人工复核，额度包含在 Top-K 中，不重复叠加。同分用预定顺序处理。

入队不等于拒贷，分别记录入队率、人工结论和实际通过率。Top-K 为待回测规则；12.40% 属于固定 cutoff 的历史结果，试点重新评价等容量下的客户质量和成本。

## 监控与处置

| 节奏 | 核心指标 | 动作 |
| --- | --- | --- |
| 每批 / 每日 | 入队率、通过率、实际拒绝率、复核量 / 时长 | 队列上限 30%，人力不足则缩小 K |
| 每月 | 通过组坏率、复核命中率、客户流失及成本 | 固定标签与观察窗口，比较等容量方案 |
| 按放款月 vintage | 同账龄 30+ / 60+ DPD 逾期率 | 接入还款与逾期数据，以成熟贷款为分母 |
| 每月 / 异常批次 | 分数与字段 PSI、缺失率 | 重点排查 n14、revolUtil 的变化批次和原因 |

**漂移优先级：** n14 PSI **0.5269**，缺失率 **5.59% → 0.00%**，先查采集与填补流程；revolUtil PSI **0.2048**，检查利用率分布、缺失、极值与客群变化。PSI 沿用开发集固定分箱。

## 试点验收

风控确认风险与成熟窗口，运营确认 Top 10% 复核预算，数据团队补齐 vintage 标签；先完成 Top-K 等容量回测，再跟踪实际通过组质量、容量和成本。现有 isDefault 标签尚未形成 30+ / 60+ 指标。
