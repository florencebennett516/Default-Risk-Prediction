Field	Description
id	为贷款清单分配的唯一信用证标识
loanAmnt	贷款金额
term	贷款期限（year）
interestRate	贷款利率
installment	分期付款金额
grade	贷款等级
subGrade	贷款等级之子级
employmentTitle	就业职称
employmentLength	就业年限（年）
homeOwnership	借款人在登记时提供的房屋所有权状况
annualIncome	年收入
verificationStatus	验证状态
issueDate	贷款发放的月份
purpose	借款人在贷款申请时的贷款用途类别
postCode	借款人在贷款申请中提供的邮政编码的前3位数字
regionCode	地区编码
dti	债务收入比
- DTI（偿债率，DSR 很多机构直接叫 DTI）：月供 / 收入（信贷审批主流）
- 广义债务收入比：债务总余额 / 年收入（宏观研究口径，网贷很少用）
月供包括：
- 房贷月供、车贷月供
- 消费贷、网贷、小贷、消金分期月供
- 信用卡：按**最低还款额**计入（风控标准做法）
- 新增拟申请贷款的月供：【申请后 DTI】会把这笔加进去
dti衡量标准：
- <30%：负担较轻
- 30%–45%：中等
- >50%：高负债，很多模型拦截线
delinquency_2years	借款人过去2年信用档案中逾期30天以上的违约事件数
ficoRangeLow	借款人在贷款发放时的fico所属的下限范围
ficoRangeHigh	借款人在贷款发放时的fico所属的上限范围
openAcc	借款人信用档案中未结信用额度的数量
这个指标用来判断**多头授信风险**
数量越高，代表借款人在多家机构同时持有可用额度，未来潜在负债扩张风险大；
totalAcc	借款人信用档案中当前的信用额度总数
pubRec	贬损公共记录的数量
该变量衡量借款人在司法、行政领域的失信与违规历史
计入
1. 欠税记录
2. 民事判决记录（尤其是债务纠纷判决）
3. 法院强制执行记录、失信被执行人（老赖）记录
4. 行政处罚记录（市场监管、税务等处罚）
不计入信用欠款
pubRecBankruptcies	公开记录清除的数量
- 贬损公共记录数量：**存量、当前还在生效的负面公共污点**，是当下风险信号
- 公开记录清除的数量：**历史污点已经了结、修复完毕的条数**
- 风控逻辑：同样有过司法负面，一部分人结清结案、记录被清除；一部分一直挂着。该变量用来区分：**有负面但是已经履约修复的群体**。
revolBal	信贷周转余额合计
循环类负债存量
revolUtil	循环额度利用率，或借款人使用的相对于所有可用循环信贷的信贷金额
revolBal/循环信贷授信总额度之和（信用卡额度+循环信用额度）
- ＜30%：通常信用表现较好
- ＞70%：高占用，现金流紧张，强负面信号
initialListStatus	贷款的初始列表状态
applicationType	表明贷款是个人申请还是与两个共同借款人的联合申请
earliesCreditLine	借款人最早报告的信用额度开立的月份
title	借款人提供的贷款名称
policyCode	公开可用的策略_代码=1新产品不公开可用的策略_代码=2
n系列匿名特征	匿名特征n0-n14，为一些贷款人行为计数特征的处理
