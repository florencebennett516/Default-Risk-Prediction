### 目标：

针对所提供的数据训练机器学习模型，预测用户违约 #isDefault 的风险

### 业务流程：


| 风控阶段                    | 用到具体字段                                                                                                                                | 目的                                                                 | 核心任务                                                                                                                   |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| 申请信息采集阶段            | loanAmnt、term、purpose、applicationType、title、employmentTitle、employmentLength、homeOwnership、postCode、regionCode                     | 收集借款人原始申请填报信息，获取基础画像，为后续核验提供原始素材     | 用户提交借款申请，采集借款诉求、就业、房产、地区等基础申请信息；不做风险判断，留存原始申请数据                             |
| 信息真实性核验阶段          | annualIncome、verificationStatus、homeOwnership、regionCode、applicationType                                                                | 校验用户填报信息是否真实可靠，过滤虚假填报申请                       | 交叉核验年收入、就业、属地信息；联合借款需采集共同借款人信息；输出验证状态标记，核验失败直接拒绝申请                       |
| 反欺诈筛查阶段              | n0‑n14（匿名特征）、postCode、regionCode                                                                                                   | 识别骗贷、冒用身份、多头申请、设备异常等欺诈行为，优先拦截欺诈类客户 | 基于行为匿名特征检测设备异常、高频申请、团伙欺诈；欺诈风险命中直接终止审批流程                                             |
| 征信数据获取与特征加工阶段  | delinquency_2years、ficoRangeLow、ficoRangeHigh、dti、openAcc、pubRec、pubRecBankruptcies、revolBal、revolUtil、totalAcc、earliesCreditLine | 从征信原始报告加工风险变量，评估借款人历史信用、负债压力             | 拉取征信数据，提取逾期记录、信用分数、负债、账户数量、公共负面记录等风险指标，作为评分模型输入                             |
| 信用评分 & 风险等级划分阶段 | grade、subGrade、全部征信特征、n0‑n14、annualIncome、dti                                                                                   | 量化借款人信用风险，划分客户风险等级                                 | 风控模型输入全部特征计算风险得分；输出贷款等级 grade/subGrade；执行硬规则：破产、严重逾期直接拒贷；高负债做降额 / 拒绝处理 |
| 授信决策（额度利率审批）    | loanAmnt、term、interestRate、installment、purpose、policyCode                                                                              | 确定最终借款合同要素，输出审批结果（通过 / 拒绝 / 降额）             | 结合风险等级确定实际放款额度、期限、贷款利率、月供；校验贷款用途合规；区分公开 / 定向产品策略；申请金额过高可执行降额审批  |
| 放款归档阶段                | id、issueDate、initialListStatus                                                                                                            | 保存完整贷款业务档案，形成贷款清单数据集                             | 用户确认合同后执行放款；生成业务唯一编号 id；记录放款时间 issueDate、贷款初始状态 initialListStatus，全量数据落库保存      |
